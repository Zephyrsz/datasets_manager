# 单音频注册

用户要求在工作空间新增“音频注册”页面，登记单个本机音频。每条只能选择一种用途：`source`（原始长音频，供后续处理）或 `reference`（参考音频，供语音克隆 TTS）。

使用独立 `audio_assets` 表保存名称、规范化绝对文件路径、单一用途、可选语言/说话人/参考文本/备注及探测出的时长、大小、采样率、声道、编码和时间。路径唯一；重复注册409并提示编辑已有条目。文件只读引用，不复制、不删除。编辑重新验证音频；移除登记只删索引。已有数据集和处理日志职责不变。

`/api/audios`提供分页、文字搜索、用途筛选及新增，`/api/audios/{id}`提供查询/完整更新/移除登记，`/api/audios/{id}/file`提供Range试听。FFprobe校验本地WAV/M4A/MP3/FLAC/OGG/OPUS/AAC/WebM/AIFF文件的真实音轨与元信息，限制超时；不接受任意URL或空/无音轨文件。读取时防止注册路径被改为跳出原目标的符号链接。缺失文件保留登记并展示不可用，允许编辑修复。

界面延续现有深绿侧栏、浅色表格及原生抽屉，新增“音频注册”导航。列表展示名称/路径、用途、时长、参考信息及试听/编辑/移除操作；登记表单包含用途单选，参考文本选填。通过音频ID即可供后续调用方选取源音频或参考音频，本轮不运行切句/ASR/TTS。移动端提供两个页面间导航，保持可操作。复用唯一播放器，避免不同页面多音轨并播。

测试以临时数据库和生成音频为准，覆盖分类、持久化、修改、重复冲突、非法路径/文件、缺失文件、Range、来源保护及与原有数据集兼容。前端构建和桌面/移动浏览器检查完成后交付。
