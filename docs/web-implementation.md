# Web 管理界面实施方案

1. 后端：增加 FastAPI 应用、请求模型和 SQLite 服务层，复用现有导入工具。提供健康检查、数据集列表/详情、注册、配置更新、重新导入、明细分页搜索、字幕修改与 WAV 流式响应。
2. 前端：React + TypeScript + Vite，独立 frontend 目录，通过 /api 代理访问后端。包含数据集库、明细页、配置侧栏、字幕编辑侧栏和底部试听播放器。
3. 数据约束：现有 schema 保持不变。写操作使用事务；SQL 值参数绑定；表名只由正整数 ID 生成；播放路径限定在注册的音频目录中。
4. 验证：临时数据库测试 API 的读写、校验、分页、音频 Range、路径边界和错误返回；原导入器测试回归；前端 TypeScript/构建检查和浏览器桌面/移动端交互检查。

配置保存更新元数据但不自动改写字幕；重新导入需要明确确认并以源清单为准。前端展示的数量、覆盖率、大小、时长均来自 API，不写入示例统计。
